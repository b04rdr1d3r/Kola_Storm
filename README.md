This template for Digital Combat Simulator aims at providing all the necessary tools to run a multiplayer campaign on the Kola Map.

it includes:
MIST
CTLD
CSAR
Skynet IADS
Moose

You have random traffic enabled and both sides have CAP missions setup automatically
It includes AWACS, tanker tracks and a CVN supercarrier

The goal is to provide a living environment...
